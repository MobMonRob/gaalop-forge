# 1.2.2

发布日期：2026-11-02。镜像：`gagislab/gaalop-forge:1.2.2`，平台 Linux x86_64。

## 一键复制

QuantumGAALOP 的 Copy code 优先使用 Clipboard API；接口不可用或拒绝写入时，在同一次点击中尝试隐藏文本框复制，随后恢复焦点和选区。普通 HTTP 页面无需额外按钮或手动选择步骤。浏览器同时阻止两种方法时，不显示复制成功。

## 概率显示

概率、振幅和总概率显示 8 位有效数字。归一化提示按总概率与 1 的偏差判定，提示容差为 1e-4；ket 子空间残差保留独立的 1e-8 阈值。页面显示偏差与残差，不修改或自动归一化计算值。

输入 b0=b1=0.7071、c0=c1=0 时，总概率为 0.99998082，偏差约 1.918e-5，在提示容差内。

## MATLAB

保留 sym 输入类型检测、依赖传播和数组初始化，补充简短的数组、基底和初始化注释。生成器保留原始 i/j 变量名，不增加原生复数绑定或改变系数表示。

滑块与归一化约束编辑器尚未实现。QRA 仍执行数值计算；本版不新增 QRA 自由参数编译。
